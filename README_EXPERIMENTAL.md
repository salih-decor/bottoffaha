# تشغيل bottoffaha — الوضع التجريبي V13/V14 (المرحلة الثالثة)

## المتطلبات
- Python 3.11 (تم الاختبار به)
- لا حزم خارجية للسيرفر نفسه (مكتبة قياسية فقط)
- للاختبارات: `pytest`

## التشغيل
1. افتح مجلد المشروع:
   `C:\Users\SUD_TEC\Desktop\bottoffaha-main`
2. شغل السيرفر:
   ```
   python app.py
   ```
   يفتح على `http://127.0.0.1:8000`
   - `GET /api/predict?row=1&user_id=123&session_id=1` → اقتراح تجريبي + `baseline_p` + `baseline_confirmed:false` + إخلاء مسؤولية (بدون نسبة ثقة)
   - `POST /api/rounds` بجسم JSON `{user_id, session_id, row, predicted_box, actual_box}` → حفظ الجولة الفعلية
   - `GET /api/stats` → إجمالي الجولات ونسبة النجاح الفعلية ونتائج كل صف وحجم العينة
   - `GET /api/report` → تقرير كل صف: المحاولات، النجاح، المعدل، فاصل ثقة Wilson 95%، p-value، وحدود الاستنتاج
   - `GET /api/export?format=csv` → تنزيل سجل الجولات CSV
   - `POST /api/import` بجسم CSV (`text/csv`) أو JSON (`{rounds:[...]}`) → استيراد مع تحقق
3. افتح `index.html` في المتصفح:
   - كلمة السر الحالية: `SOFY` (كما في النسخة الأصلية)
   - أدخل ID تجريبي (5 أحرف على الأقل)
   - زر `سـكـربـت الـتـفـاحـة` → `اقتراح تجريبي للصف التالي`
   - بعد ظهور النتيجة الحقيقية في لعبة 1xBet، أدخل الصندوق الفعلي (1-5) في مربع `تسجيل النتيجة الفعلية` ثم `حفظ`
   - `تحديث` للإحصائيات، `تقرير مفصل` لفاصل الثقة، `تصدير/استيراد CSV` للنسخ الاحتياطي

## قواعد اللعبة وخط الأساس (مهم)
- انظر `game_config.json` و `docs/GAME_RULES.md`.
- الافتراض الحالي: 1 آمن من 5 → baseline=0.2 **غير مؤكد**. إذا كانت طاولتك 4 آمنة من 5 فالأساس 0.8.
- لا تغير `confirmed=true` إلا بعد مشاهدة الطاولة الفعلية.

## الاختبارات
```
python -m pytest tests/ -v
```
- 38 اختباراً: تخزين + خط أساس مناسب + تقسيم زمني + Wilson + Bonferroni + فصل المجموعات + هجرة CSV + منع تكرار + توقيتان + بيانات عشوائية/منمطة + عدم وجود اتصال 1xBet.
- اختبار تكامل حي ناجح: predict → post (موثق وغير موثق) → duplicate مرفوض → report (موثق/مصحح) → export/import (نظفت بياناته، `data/` فارغة).

## جودة البيانات (المرحلة الحالية)
- كل سجل: `round_id` فريد + `predicted_at` (قبل اللعب) + `ts` (بعد الظهور) + `num_boxes/num_safe/level` (أو unknown بدون افتراض).
- لا يحتسب نجاح إلا `hit_verified` (توقع محفوظ قبل النتيجة). القديمة بدون توقيت تبقى `unverified`.
- الإحصائيات مفصولة حسب `boxes|safe|level` والجلسة — الخلط يحذر ويبطل الإجمالي.
- التقرير يصحح `Bonferroni` (alpha/عدد الصفوف) ويعرض شروط الصلاحية.
- CSV الجديد V2 متوافق قراءة مع القديم، مع منع التكرار داخل الملف وضد الملف.
